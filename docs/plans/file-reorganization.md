# File Reorganization Plan

## Goals
1. **Flat over nested** - No more than 2 levels deep for docs/notebooks
2. **Clear naming** - File names describe content, not location
3. **No duplication** - One source of truth for each topic
4. **Easy navigation** - New team member can find anything in <30 seconds

---

## New Structure

```
docs/
├── README.md                       # Index of all documentation
├── guides/                         # How to do things
│   ├── getting-started.md          # New member onboarding
│   ├── connecting-to-database.md   # Database access (was data-infrastructure.md)
│   ├── api-keys.md                 # API configuration
│   ├── environment-setup.md        # Dev environment
│   ├── git-workflow.md             # Git/GitHub workflow
│   └── using-claude-code.md        # Claude Code tips
├── reference/                      # What things are
│   ├── database-schema.md          # Full schema docs (was DATABASE_GUIDE.md)
│   ├── polymarket.md               # Polymarket platform info
│   ├── kalshi.md                   # Kalshi platform info
│   ├── sports-betting.md           # Betting concepts
│   └── skills.md                   # Custom Claude skills
└── plans/                          # Implementation plans
    ├── oddsharvester-integration.md
    └── file-reorganization.md      # This file

research/
└── notebooks/
    ├── getting-started.ipynb       # Interactive DB tutorial
    ├── price-dynamics.ipynb        # Price analysis (Dietrich's)
    └── _template.ipynb             # Template for new research

├── PROJECT_LOG.md
```
